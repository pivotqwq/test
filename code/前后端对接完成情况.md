## 技术实现要点

### 1. API调用统一规范
- 所有API调用使用fetch方法
- 统一添加Authorization头: `Bearer ${token}`
- 统一添加Content-Type头: `application/json`
- 统一错误处理和用户提示

### 2. 数据字段映射
- 前端字段名按后端标准统一命名
- 使用PascalCase命名规范（如PatientId, MedicalRecordNo）
- 处理null/undefined值的默认显示

### 3. 错误处理机制
- API调用失败时显示具体错误信息
- 网络错误时提供友好的用户提示
- 部分API失败时使用模拟数据作为后备

### 4. 加载状态管理
- 所有数据加载页面都有loading状态
- 使用Element Plus的loading组件
- 防止用户重复操作

### 5. 分页和筛选
- 支持分页参数page和limit
- 支持按条件筛选数据
- 分页组件正确显示总页数
